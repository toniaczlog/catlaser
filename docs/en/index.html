GOOD TO KNOW

Questions & answers.

Is CatLaser free?

Yes. Free, open source (MIT), with no ads or subscriptions.

Do I need to install it?

No. Download the ZIP, extract it, and run CatLaser.exe on Windows 10/11 x64.

Why might Windows SmartScreen warn me?

The executable is not digitally signed yet. Source code is public on GitHub and the app is built with GitHub Actions.

Is it safe for cats?

This is only an effect on a monitor, not a physical laser beam. Supervise your cat to prevent screen scratching, keep sessions short, and end play with a physical toy they can actually catch.

How do I turn off the laser?

Press Ctrl + Alt + L or use the Windows system tray. Exiting restores your cursors. If CatLaser crashes, restart it to restore the cursor scheme.
