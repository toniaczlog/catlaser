DOBRZE WIEDZIEĆ

Pytania i odpowiedzi.

Czy CatLaser jest darmowy?

Tak. Jest bezpłatny, open source (MIT), bez reklam i bez subskrypcji.

Czy muszę instalować program?

Nie. Wystarczy pobrać ZIP, rozpakować i uruchomić CatLaser.exe na Windows 10/11 x64.

Dlaczego Windows SmartScreen może ostrzegać?

Plik EXE nie jest jeszcze podpisany cyfrowo. Kod źródłowy jest publiczny na GitHubie, a aplikację kompiluje GitHub Actions.

Czy to bezpieczne dla kota?

Program nie emituje prawdziwego lasera — wyświetla efekt na monitorze. Pilnuj jednak, aby kot nie drapał ekranu, rób krótkie sesje i zakończ zabawę prawdziwą zabawką do złapania.

Jak wyłączyć laser?

Ctrl + Alt + L lub menu programu przy zegarze. Wyjście przywraca kursory Windows. Po awaryjnym zamknięciu można uruchomić CatLaser ponownie, aby przywrócić kursory.
